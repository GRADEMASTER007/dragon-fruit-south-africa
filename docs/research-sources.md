# Verified implementation references

TanStack Start supports Node hosting with its Nitro Vite integration and the production command `node .output/server/index.mjs`. This preserves the source application's server-rendered framework while allowing Manus container deployment. References: https://tanstack.com/start/latest/docs/framework/react/guide/hosting and https://nitro.build/examples/vite-ssr-tss-react (read 15 October 2026).

PayPal's official Currency codes reference, updated 17 August 2026 and read in the rendered browser on 15 October 2026, lists supported REST payment currencies including USD, EUR and GBP but not ZAR. Existing client-side PayPal ZAR checkout is not a valid retained implementation. The owner has been asked to approve USD international quotations or an explicit automatic conversion rate/pricing policy. Reference: https://developer.paypal.com/api/codes/currency.
